## 📖 درباره‌ی پروژه

افسانه‌ها و قصه‌های محلی، دیوها، پری‌ها، روایت‌های عامیانه و باورهای کهن شهرها و روستاهای ایران بخش بزرگی از هویت فرهنگی ما هستند که قرن‌ها سینه به سینه نقل شده‌اند، اما امروز در آستانه‌ی فراموشی قرار دارند.

**«افسانه‌ها»** یک پایگاه داده‌ی کاملاً آزاد، مردمی و متن‌باز است که به عنوان یک حافظه‌ی دیجیتال جمعی عمل می‌کند. هر کس از هر گوشه‌ی ایران — حتی بدون داشتن حساب گیت‌هاب — می‌تواند افسانه‌ی منطقه، روستا یا شهر خود را با گویش و نام خود ثبت کند تا برای همیشه زنده بماند.

## ✨ ویژگی‌های برجسته

* **🗺️ نقشه‌ی وکتور و تعاملی ایران:** پیاده‌سازی شده با SVG خالص (بدون وابستگی به Leaflet یا Mapbox)، دارای پروجکشن دقیق جغرافیایی، افکت پارالکس سه‌بعدی و فیلتر آنی افسانه‌ها بر اساس استان.
* **🚀 مهندسی صفر وابستگی (Zero-Dependency):** بدون فریم‌ورک‌های سنگین؛ تمام فرانت‌اند با Vanilla HTML5, CSS3 و Modern JavaScript نوشته شده تا حداکثر سرعت لود (Lighthouse 100/100) و ماندگاری را داشته باشد.
* **🗄️ گیت به عنوان پایگاه‌داده (Git as Database):** افسانه‌ها در قالب فایل‌های تمیز و خوانای Markdown ذخیره می‌شوند؛ به این معنی که این آرشیو حتی بدون اینترنت یا وب‌سایت هم به عنوان فایل‌های متنی تا ده‌ها سال ماندگار است.
* **🤝 مشارکت عمومی بدون نیاز به گیت‌هاب:** به کمک یک Cloudflare Worker امن و سبک، کاربران عادی از طریق فرم تحت وب افسانه‌ها را ثبت می‌کنند و ورکر به صورت خودکار یک Pull Request در گیت‌هاب باز می‌کند.
* **🎙️ پشتیبانی از روایت صوتی (Audio):** امکان پیوست فایل‌های صوتی برای ثبت صدای راویان محلی و سالمندان با لهجه‌های بومی.
* **📖 حالت مطالعه بدون حواس‌پرتی (Reading Mode):** امکان مطالعه متمرکز افسانه‌ها شبیه به کتاب چاپی با فشردن یک کلید.
* **❄️ جلوه‌های فصلی هوشمند:** تشخیص خودکار مناسبت‌هایی مثل شب یلدا و نوروز با تم اختصاصی و ریزش برف.
* **📱 پشتیبانی کامل از PWA:** امکان نصب به عنوان اپلیکیشن روی موبایل و مرور آفلاین بدون نیاز به اتصال دائم اینترنت.
* **🌐 دوزبانه (فارسی / انگلیسی):** پشتیبانی کامل از تغییر زبان و سوئیچ جهت صفحه (RTL/LTR).

## 📂 ساختار مخزن

```text
├── index.html              # صفحه اصلی (جستجو، نقشه ایران، فیلترها و گرید کارت‌ها)
├── legend.html             # نمایش دینامیک یک افسانه
├── contribute.html         # فرم ارسال افسانه توسط کاربران
├── contributors.html       # تالار افتخارات مشارکت‌کنندگان
├── about.html              # درباره پروژه و راهنما
├── config.json             # تنظیمات اصلی سایت و آدرس API ورکر
├── sw.js                   # سرویس‌ورکر جهت کش و قابلیت آفلاین (PWA)
│
├── assets/
│   ├── css/style.css       # استایل‌های دارک/لایت، پارالکس و عمق سه‌بعدی
│   ├── js/                 # منطق سایت بدون کتابخانه خارجی (map, i18n, app, season...)
│   └── data/               # دیتای پیش‌بیلد JSON استان‌ها و مانیفست افسانه‌ها
│
├── legends/                # ⬅️ گنجینه متن‌ها! هر افسانه در پوشه اختصاصی
│   └── <نام-استان>/
│       └── <نام-افسانه>/
│           ├── fa.md       # متن اصلی به فارسی با متادیتا
│           ├── en.md       # ترجمه انگلیسی (اختیاری)
│           └── voice.mp3   # صوت قصه (اختیاری)
│
├── scripts/
│   ├── build.mjs           # سازنده استاتیک صفحات SEO، نقشه سایت و RSS
│   └── build-index.mjs     # تولیدکننده دیتابیس JSON
│
└── worker/                 # ربات کلودفلر جهت ثبت خودکار PR از طریق فرم
